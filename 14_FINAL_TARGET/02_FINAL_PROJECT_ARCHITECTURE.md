- AI operations copilot
- controlled tool-using agent

## Example user flow
1. Device reports abnormal pressure.
2. Telemetry service stores event.
3. Anomaly model scores it.
4. Alert is created.
5. Angular/React dashboard updates realtime.
6. Operator asks AI: "Why is this device abnormal?"
7. RAG retrieves relevant manuals/SOPs.
8. AI combines telemetry + documents.
9. Response includes evidence/citations.
10. Agent can propose a safe action.
11. Human approves risky action.
12. Audit log records everything.
