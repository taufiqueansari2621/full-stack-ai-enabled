# How to use this roadmap

## Project ladder
Do not jump directly to the capstone.

Build:
P01 → P05 → P10 → P15 → P20 → P25 → P30

Each project should introduce a new engineering capability.

## Definition of done
A topic is NOT complete when you watch a tutorial.

It is complete when you can:
- explain it without notes
- implement it
- debug it
- test it
- identify trade-offs
- answer 5 interview questions about it

## Weekly score
Score each week:
- Learning: /10
- Coding: /10
- DSA: /10
- Project: /10
- Interview: /10
- Communication: /10

Target average: 8+.

## Rule for AI
Do not make your portfolio 10 clones of ChatGPT.
Build AI into real products and demonstrate:
- retrieval quality
- evaluation
- security
- latency
- cost
- observability
- business value
