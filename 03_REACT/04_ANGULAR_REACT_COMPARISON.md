# Angular vs React — interview sheet

Know how to explain:

Angular:
- opinionated framework
- DI
- RxJS ecosystem
- routing/forms/testing patterns
- templates
- signals
- larger built-in platform

React:
- UI library/core model
- JSX
- composition
- hooks
- ecosystem-driven architecture
- state/data-fetching choices

Be able to implement the same feature in both.

Project:
P20: Build the same mini CRM twice:
1. Angular
2. React

Compare:
- architecture
- state
- testing
- performance
- developer experience
- bundle/runtime behavior
