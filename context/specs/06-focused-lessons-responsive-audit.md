# Unit 06: Focused Lesson Pages and Responsive Audit

> Historical specification: the one-task-at-a-time foundation interface was
> superseded by Unit 09 Full Learning Mode. Its detailed authored content and
> responsive verification requirements remain in use.

## Goal

Make every foundation subtopic a substantial, distraction-free learning page
and verify the complete application at representative desktop, laptop, tablet,
and mobile sizes.

## Focused Learning Behavior

- Display exactly one selected lesson task in the main workspace.
- Keep every task directly selectable in the compact lesson roadmap.
- Use Previous and Next as real page navigation through the complete lesson,
  then continue into the adjacent lesson.
- Persist the exact selected task for the active learner.
- Provide a visible task counter and progress bar in addition to the active
  sidebar state.

## Detailed Foundation Content

Each of the 18 core teaching subtopics across computer fundamentals, web
fundamentals, HTML, accessibility, CSS, and JavaScript includes:

- a beginner-friendly explanation;
- why the concept matters;
- a familiar analogy;
- an ordered step-by-step process;
- a text-based visual model;
- a realistic application;
- an immediate practice challenge; and
- concise key takeaways.

Goals, vocabulary, mistakes, exercises, the knowledge check, and interview
revision are also independent navigable task pages.

## Responsive Verification Matrix

The automated Chrome audit opens all 12 primary workspaces at:

- 1440 × 900 dark mode;
- 1280 × 800 light mode;
- 1024 × 768 dark mode;
- 768 × 1024 light mode;
- 390 × 844 dark mode; and
- 320 × 568 light mode.

Every combination is checked for document-level horizontal overflow. The full
functional flow still verifies profiles, persistence, roadmap navigation,
practice, assessment, certificates, projects, reviews, interview, search, and
reset behavior.
