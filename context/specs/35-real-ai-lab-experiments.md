# Input-dependent AI lab experiments

Replace all fixed outputs and fabricated telemetry. Local chunking, validated
read-only tool execution, and lexical evaluation are genuine computations with
explicit limits. Learned embeddings, cosine search, top-k retrieval, prompt
generation, grounded generation, and a bounded retrieve/generate/stop workflow
use the existing authenticated Workers AI boundary. No autonomous file changes.

Only explicitly entered source/query text is shared. Model calls require a cloud
account and consent, share the existing per-user hourly AI quota, bound batches
and input sizes, and record usage metadata. Do not retrieve private account data.
Use real measured latency, estimated token counts labelled as estimates, cosine
similarity labelled as similarity (not quality), lexical F1 labelled as a
heuristic (not factual correctness), and unknown rather than invented charges.

Test input dependence, chunk bounds, vector validation, cosine ranking,
tool-schema rejection, no automatic side effects, auth/error/cancel recovery,
and model response boundaries. Public regression uses a local chunking experiment;
authenticated verification must exercise the actual embedding and generation.
