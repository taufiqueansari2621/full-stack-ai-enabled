# System Design Scenario Lab

## Outcome

Forge provides every system-design practice scenario, component, connection,
and explanation prompt required by the Forge 2.0 brief.

## Scenarios

The typed catalog includes URL Shortener, Chat Application, Notification
Service, E-commerce Platform, Video Platform, Search System, and AI RAG
Platform. Selecting a scenario loads a relevant five-or-more-component starter
flow and concise problem brief.

## Canvas

The component palette contains Client, CDN, Load Balancer, API, Service,
Database, Cache, Queue, Object Storage, Search, Vector Database, and AI Service.
Added components connect in flow order; individual nodes can be removed and the
canvas can be cleared or replaced by another scenario starter.

## Explanation evidence

Every design asks the learner to explain scaling, availability, consistency,
security, failure handling, cost, and trade-offs. Saved evidence continues
through the existing learner-scoped local/cloud progress boundary.

## Verification

Focused tests enforce the exact seven scenarios, 12 components, starter-flow
validity, and seven prompts. Local and production browser gates verify the
rendered scenario count, palette, connected flow, prompts, and mobile safety.
