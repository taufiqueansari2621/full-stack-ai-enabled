# Complete DSA Visualizer

## Outcome

The Advanced Labs DSA workspace covers every data structure and algorithm named
in the Forge 2.0 brief through deterministic, inspectable traces.

## Catalog

The typed domain catalog contains arrays, linked lists, stacks, queues, hash
maps, trees, graphs, sorting, binary search, recursion, breadth-first search,
depth-first search, and dynamic programming.

Each step records:

- visible data-structure state;
- the current operation;
- current variables;
- the active call stack;
- algorithm time and space complexity.

## Controls

Learners can move Previous or Next, Play and Pause an automatic trace, and
Reset to the initial state. Changing algorithms stops playback and resets the
step so state never leaks between traces.

## Verification

Focused tests enforce the exact required catalog and complete explanatory data
for every step. Browser smoke and production verification assert all 13 options,
controls, variables, call-stack output, persistence compatibility, and mobile
overflow safety.
