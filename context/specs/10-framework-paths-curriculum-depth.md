# Unit 10: Framework Paths and Curriculum Depth

## Goal

Make React and Angular first-class, selectable frontend specializations and
expand the whole catalog toward a zero-to-professional engineering journey.

## Framework Selection

- Every learner completes the shared frontend platform foundation.
- A learner can select React, Angular, or Both.
- The choice is stored per local learner profile.
- Only relevant specialization modules contribute to frontend and overall
  progress; choosing one framework does not require the other.
- The choice may be changed without deleting existing completion evidence.

## Curriculum Depth

- Restore DSA as a navigable roadmap phase.
- Add missing frontend, backend, data, system-design, AI, DevOps, cloud,
  incident, and senior architecture topics.
- Expand generated Full Learning Mode chapters for every catalog topic.
- Preserve existing IDs and completion evidence wherever content remains.

## Acceptance Criteria

1. Frontend Engineering visibly offers React, Angular, and Both.
2. Angular includes foundations, DI, RxJS, Signals, applications, state,
   testing, debugging, performance, production, projects, and interviews.
3. React includes foundations, hooks/state, applications, testing, internals,
   Next.js, production, projects, and interviews.
4. The framework preference survives refresh and is learner-scoped.
5. Roadmap and dashboard progress use the selected curriculum.
6. Every new topic opens Full Learning Mode and participates in navigation.
7. Lint, build, isolated browser flow, and responsive overflow checks pass.
