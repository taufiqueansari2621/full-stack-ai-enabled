# Unit 07: Deep Dive Learning Loop

## Goal

Turn each catalog topic from a primarily reading-based lesson into an active
learning loop that asks the learner to predict, inspect, transfer, and teach.

## Learning Behavior

- Keep the complete topic explanation and continuous Full Learning Mode intact.
- Ask for a prediction before revealing the worked reasoning.
- Offer progressive help instead of exposing every answer immediately.
- Require a transfer response that applies the idea to a changed situation.
- End with a teach-back and an honest confidence rating.
- Save the learner's complete deep-dive response as durable evidence.
- Never award topic completion from self-confidence alone.

## Acceptance Criteria

1. Every catalog topic exposes the same four-stage Deep Dive Lab.
2. Later stages remain visibly gated until the learner completes the active step.
3. A learner can move backward without losing their in-session responses.
4. Finishing the lab records an attempt and a saved learning note.
5. The experience works with keyboard controls and at mobile widths.
6. Lint and production build pass.
