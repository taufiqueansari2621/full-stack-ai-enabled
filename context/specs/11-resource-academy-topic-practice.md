# Unit 11: Resource Academy and Topic Practice

## Goal

Connect the broad curriculum to authoritative learning material and meaningful
practice without copying third-party courses or presenting external reading as
Forge mastery.

## Product Behavior

- Add a Resource Academy containing official documentation, trusted courses,
  coding practice, projects, and interview-preparation resources.
- Explain what each external resource is useful for instead of presenting an
  uncurated link directory.
- Expose a small, relevant official-resource set inside every catalog lesson.
- Add a topic practice mode covering every visible catalog topic at Easy,
  Medium, and Hard difficulty.
- Save open-ended practice artifacts per learner, topic, and difficulty.
- Keep existing quick-check practice and its stored attempt history intact.
- Show three role roadmaps: Frontend Developer, Full-Stack Developer, and AI
  Engineer, each progressing from foundation to professional evidence.

## Integrity Rules

1. External links open safely and are clearly attributed.
2. Visiting an external resource never grants completion, XP, or mastery.
3. Saving an open-ended response records evidence of work, not correctness.
4. Official documentation is labeled separately from community courses and
   commercial practice platforms.
5. Resource descriptions are original summaries, not copied course content.

## Acceptance Criteria

1. Resources is a routable primary workspace and is included in global search.
2. The resource catalog can be filtered by search, technology, and resource
   type.
3. Every curriculum phase resolves to at least one relevant authoritative
   resource set.
4. Practice offers Quick Checks and Topic Drills without regressing existing
   attempts.
5. Every selectable topic has Easy, Medium, and Hard prompts, success criteria,
   and a persistent response.
6. Learner reset removes topic-practice artifacts.
7. The new surfaces work without horizontal overflow from 320px upward.
8. Lint, production build, and isolated browser smoke checks pass.
