# Unit 08: Topic Mastery Studio

## Goal

Give every catalog topic a professional learning progression from foundational
explanation to independent production reasoning, with durable learner artifacts.

## Behavior

- Present five levels: Foundation, Guided, Applied, Debug, and Professional.
- State a concrete outcome, task, and success criteria for each level.
- Unlock levels sequentially so guidance fades in a coherent order.
- Keep previous submissions available when the learner revisits a topic.
- Allow a learner to improve and resubmit an artifact.
- Treat submissions as evidence of practice, never as automatic mastery.
- Keep formal topic completion gated by the existing checkpoint.

## Persistence

Each artifact records a stable lesson ID, level, response, and update time in
the learner-scoped local repository. Invalid or absent persisted data falls
back safely to an empty collection.

## Acceptance Criteria

1. Every catalog topic displays the same five-level studio.
2. The active level gives an outcome, authentic task, and explicit rubric.
3. Submissions survive refresh and remain isolated by learner profile.
4. Learners can revise saved work without duplicate artifacts.
5. Keyboard navigation and mobile layouts remain usable.
6. Lint, production build, and browser smoke checks pass.
