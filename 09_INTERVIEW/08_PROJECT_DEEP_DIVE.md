# Project Deep Dive

For every major project prepare a 10-minute story:

1. Problem
2. Users
3. Constraints
4. Architecture
5. Data model
6. API
7. Hardest decision
8. Biggest bug
9. Performance issue
10. Security
11. Testing
12. Monitoring
13. Scaling
14. Trade-offs
15. What you would change

Never say:
"I just followed a tutorial."

You must own every important design decision.
